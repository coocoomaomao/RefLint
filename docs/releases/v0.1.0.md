# RefLint v0.1.0

The first public alpha release of **RefLint — ESLint for academic references**.

## Highlights

- local BibTeX quality checks
- duplicate DOI and title detection
- required-field checks for common entry types
- DOI syntax and year sanity checks
- duplicate citation-key / field detection
- recursive folder scanning
- strict mode and CI-friendly exit codes
- optional online DOI resolution
- DOI metadata comparison for title, year, and venue
- Python 3.10–3.12 support

## DOI verification

Local checks remain the default:

~~~bash
reflint check references.bib
~~~

Opt in to DOI resolution and metadata comparison:

~~~bash
reflint check references.bib --online
~~~

The online verifier uses DOI content negotiation for CSL-JSON metadata. It distinguishes a resolver/network outage from a DOI that explicitly fails to resolve.

## Install

~~~bash
pip install reflint
~~~

## Status

RefLint v0.1.0 is an alpha release. Online metadata differences are deliberately conservative: title mismatches can warn, while year and venue differences are informational because legitimate publication metadata can vary across online-first and issue records.
